公司项目 · 终端运维 Agent 与 Harness 架构

联想设备管理平台
企业终端运维 Agent 智能工作流

在纳管 100 万+ 终端的成熟 B 端平台中引入对话式 Agent。遵循“凡能用确定性代码约束绝不交由概率模型自由发挥”原则，首创“AI 意图编排 + 平台确定性鉴权拦截 + HITL 用户最终确认”三方责任模型，将复杂跨模块操作由 7 步缩短至 2 步。

  • 风险分级路由与 Approval Token：只读查询走轻量 Tool Calling；关机等高危操作后端强校验一次性审批 Token，杜绝诱导绕过
  • 9 大功能架构重构 (Workflow vs Agent)：破除泛 Agent 化，将 80% 业务降级为确定性工作流，Token 节省 70%，延迟从 3.5s 压进 0.9s
  • 全生命周期评测即 PRD：搭建覆盖正常、多轮指代、参数残缺与越权的百条级 Eval Pack，高危未授权 100% 确定性拦截

我擅长什么，如何用工程化思维驾驭 AI

能力不是调参玩梗，而是在概率模型与企业严肃业务之间，构建确定、可靠的工程控制平面。

复杂业务 Agent Harness 与安全护栏

深谙 Agent = Model + Harness 工程范式。首创“AI 意图编排 + 平台确定性鉴权 + HITL 用户最终确认”三方责任模型；擅长前置状态探针、Schema 槽位校验、高危两级确认与异常降级恢复（Fallback & Recovery），从系统层根治模型幻觉与越权失控。

  • 区分只读查询与写操作，严格限制执行半径
  • 设计参数残缺追问、同名歧义识别与离线预检自愈
  • 沉淀高危误触 100% 确定性拦截规范
意图路由 状态探针 RBAC拦截 HITL确认 审计自愈

企业级 RAG 与 Context Engineering

从知识资产化角度治理上下文腐化（Context Rot）。精通 H2/H3 业务语义分块与生效时间元数据强过滤，杜绝新旧版本混淆；设计“回答依据强制展示 + 原文跳转锚定 + 代码级明确拒答”三层防线，沉淀 Badcase 线上治理自愈飞轮。

0-1 原型交付与 Eval Harness 评测体系

坚持“评测即 PRD”。擅长搭建百条级覆盖正常指令、参数残缺、时效冲突与越权诱导的 Golden Dataset（黄金测试集）；以检索召回率（Recall@K）、答案忠实度与拒答准确率设立客观验收硬指标，实现持续自动化回归验收。

7年 B 端严谨系统底座 × 混合架构设计

深刻理解多租户、复杂权限与业务链路。擅长“确定性规则引擎 + 概率大模型”混合分工与大小模型分级路由；兼备 React/Vite 原型代码交付与 UX 可用性工程能力，让 AI 不确定性在人机交互中可感知、可核验、可解释。
